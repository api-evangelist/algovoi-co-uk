# AlgoVoi

> AlgoVoi is an AI company: run by an AI agent workforce and built for AI agents (a human founder
> approves anything public). It builds self-hosted, post-quantum, offline-verifiable infrastructure
> in two lines: a Verifiable Compliance Suite for long-term regulated records and evidence, and a
> chain-agnostic, multi-protocol agentic payment rail (x402, AP2, A2A, MPP) live across twelve mainnet
> chains (Algorand, Base, Monad, Polygon, Arbitrum, OP, Arc, Solana, Stellar, Hedera, Voi, Tempo), callable pay-per-call at
> pay.algovoi.co.uk with no account and no API key. The self-hosted and compliance products run on the
> customer's own infrastructure, air-gap capable, signed with Falcon-1024 and ML-DSA-65, and verifiable
> offline against a published public key with no vendor in the trust path. One-time perpetual licences.

## Post-quantum long-term evidence (reseal existing signatures, audit at scale)

A ladder of self-hosted tools for documents already signed with classical RSA or ECDSA, which stay
provable only while those algorithms stay unforgeable. Verify one document free, re-anchor the ones
you hold into post-quantum attestations, or batch-audit a whole archive with a signed report. The
signing is Falcon-1024 plus ML-DSA (65 or 87), RFC-3161 timestamped, and offline-verifiable against
the free open verifier with no vendor in the trust path.

- [Reseal (overview)](https://algovoi.co.uk/reseal.html): quantum-seal the documents you already signed; re-anchor a classical RSA/ECDSA signature into a post-quantum, timestamped, offline-verifiable attestation while the original still verifies. Free open verifier plus a licensed sealer from 99 USD.
- [Reseal (docs)](https://docs.algovoi.co.uk/reseal.md): the free av-reseal-verify tool, the two signing profiles, the trust model, and how to seal and verify.
- [Evidence Auditor (overview)](https://algovoi.co.uk/evidence-auditor.html): batch-verify a whole archive of signed documents, flag the weak, expired, broken-chain and quantum-exposed ones, and produce a signed, tamper-evident audit report an auditor checks with the free verifier. From 599 USD.
- [Evidence Auditor (docs)](https://docs.algovoi.co.uk/evidence-auditor.md): the ladder, what it flags per document, the self-verifying report, and the baseline diff.

## Hosted payable rail (chain-agnostic, twelve live chains, pay per call, no API key)

A hosted, tenant-free, chain-agnostic verification rail at https://pay.algovoi.co.uk that any AI agent
can call and pay per request over x402, live across twelve mainnet chains (Algorand, Base, Monad, Polygon, Arbitrum, OP,
Solana, Stellar, Hedera, Voi and Tempo), with no account and no API key: the payment is the authentication. The
agent pays in USDC on whichever of the twelve chains it already holds funds on. Two live skills, each
0.01 USDC per call, each returning an offline-verifiable Ed25519 receipt that recomputes from its own
bytes: verify an x402 or AP2 payment receipt, and verify an RFC 9421 HTTP message signature. The live
agent card lists the current lanes and the exact per-lane payment binding.

Chain-agnostic agent payment negotiation: before paying, an agent can POST the chains and protocols it
supports (CAIP-2 ids or plain names) to https://pay.algovoi.co.uk/pay/v1/negotiate and receive the
settlement lanes it shares with the rail plus a recommended pick, across twelve mainnet chains and the
x402, MPP, AP2 and A2A protocols. It is read-only and unauthenticated: it mints no token and settles
nothing, so two agents that speak different chains can converge on one lane before any payment moves.

- [The multi-protocol agent-payment rail](https://algovoi.co.uk/agent-payment-rail.html): the one rail that answers over all four agent-payment protocols (x402, A2A, MPP, AP2) at once, converging on one settlement core and one offline-verifiable Ed25519 receipt, chain-agnostic across twelve mainnet lanes. The interop layer above the per-chain facilitators, with the live four-protocol wire shapes, an interactive lane negotiation, and an in-browser offline receipt verifier.
- [Negotiate a payment lane](https://pay.algovoi.co.uk/pay/v1/negotiate): the chain-agnostic capability match. POST {chains, protocols} to get common_lanes, common_protocols, and a recommended pick; GET returns the full capability set. Read-only, no account.
- [AlgoVoi Pay (hosted rail)](https://docs.algovoi.co.uk/algovoi-pay): the hosted pay-per-call rail, its two paid verification skills, the x402 402-to-receipt flow, and how to verify a receipt offline.
- [Hosted rail agent card](https://pay.algovoi.co.uk/.well-known/agent-card.json): the A2A and x402 agent card declaring the skills, the payable lanes, and did:web:pay.algovoi.co.uk.
- [Hosted rail machine index](https://pay.algovoi.co.uk/pay/v1/index): the x402 index with per-call pricing, supported networks, and the payment-binding contract.

## Ways to run AlgoVoi (three deployment models)

Three ways to consume the same chain-agnostic rail: hosted pay-as-you-go (tenant-free, per-call, no account), hosted multi-tenant (a managed account with per-tenant keys, limits, payout destinations, hosted checkout and an operator dashboard), and self-hosted (the Payment Rails bundle you run on your own infrastructure). The same signed, offline-verifiable receipts, post-quantum where applicable, across all three.

On price: the self-hosted Payment Rails bundle is a one-time perpetual licence with no per-transaction and no per-agent fee (you pay only chain gas), and the hosted rail is a flat 0.01 USDC per call with no account and no percentage cut, unlike typical hosted x402 facilitators that take a per-transaction or percentage fee. The hosted rail settles chain-agnostically across twelve mainnet chains (Algorand, Base, Monad, Polygon, Arbitrum, OP, Arc, Solana, Stellar, Hedera, Voi, Tempo); the self-hosted bundle ships seven of them today.

- [Ways to run AlgoVoi](https://algovoi.co.uk/ways-to-run.html): the three-model comparison (hosted pay-as-you-go, hosted multi-tenant, self-hosted).
- [Hosted multi-tenant platform](https://algovoi.co.uk/commercial.html): a managed account with per-tenant isolation, hosted checkout and an operator dashboard; start a trial at api.algovoi.co.uk/signup.
- [Keystone: the agentic-payment trust layer](https://algovoi.co.uk/keystone.html): identity, authority, policy, decision, execution and one verdict, byte-verifiable offline.
